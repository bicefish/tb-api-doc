Getting Started

Getting Started with technikboerse Interfaces

This guide walks you through the first steps of your integration. Whether you choose the classic path via XML data exchange or prefer using the modern REST API: You will find the appropriate orientation for your scenario here.

Orientation

Choose your integration scenario

Our interfaces can be operated in different directions and technologies. To get started, choose the scenario that matches your goal.

I want to send data to technikboerse

Partner → technikboerse

Choose this path if your system provides listings or related data to technikboerse.

  • Decide whether XML or REST is the appropriate integration method
  • Review onboarding and setup requirements
  • Obtain the required credentials and artifacts
  • Validate the data flow in the test phase

Relevant Pages:

  • Onboarding Process
  • Transport & Operating
  • REST API Overview

I want to receive data from technikboerse

technikboerse → Partner

Choose this path if technikboerse provides data that your system retrieves or receives.

  • Choose between XML or REST integration
  • Understand the agreed delivery model and timing
  • Understand the XML structure and core elements
  • Validate the processing flow before productive use

  • Transport & Operating
  • Quickstart (XML)
  • REST API Overview
