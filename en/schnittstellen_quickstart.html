Getting Started

Export Your First Machine

This guide will walk you through creating a valid XML file to send your first machine advertisement to technikboerse. The technikboerse XML standard is a robust, hierarchical format designed for reliable data exchange.

1

Preparation & Credentials

Before you start coding, ensure you have the following technical information from technikboerse:

  • Sender Name: Your unique system identifier (e.g., provider-xy).
  • Dealer GUID: The unique technical key for the dealer whose machines you are exporting.
  • Category IDs: A list of valid category IDs to correctly classify your machines.

Tip: Download the XML Schema (XSD) to set up your IDE validation.

2

The XML Root (exchange)

Every file starts with the <exchange> element. This contains global metadata about the export.

<exchange>
  <senderName>your-provider-id</senderName>
  <exportDate>2024-05-12T06:00:00</exportDate>
  <transferMode>full</transferMode>
  <dealers> ... </dealers>
</exchange>

See the Root Element Reference for details on transferMode.

3

The Dealer Block

Inside <dealers>, add your dealer. The guid is the primary key.

<dealer guid="dealer-unique-key-123">
  <info>
    <name>Sample Machinery Ltd.</name>
  </info>
  <ads> ... </ads>
  <contacts> ... </contacts>
</dealer>

Learn more about Dealer Attributes.

4

Define a Contact Person

Contacts are defined at the dealer level and referenced by machines. Define them in the <contacts> container.

<contact id="1">
  <first_name>John</first_name>
  <last_name>Doe</last_name>
  <email>j.doe@example.com</email>
</contact>

Check the Contact Reference for fields like gender and phone.

5

The Machine (ad)

The <ad> element represents the machine. Place it inside the dealer's <ads> container.

<ad guid="machine-789" category_id="210">
  <info>
    <brand>Fendt</brand>
    <model>724 Vario</model>
    <year>2022</year>
  </info>
  <price currency="EUR" taxtype="inclusive">185000</price>
  <contact_ids>
    <contact_id>1</contact_id>
  </contact_ids>
</ad>

Detailed field lists can be found in the Ad Reference and Prices & Media.

Complete Minimal Example

Download XML 
<?xml version="1.0" encoding="UTF-8"?>
<exchange>
  <senderName>provider-demo</senderName>
  <exportDate>2024-05-12T06:00:00</exportDate>
  <transferMode>full</transferMode>
  <dealers>
    <dealer guid="dealer-1001">
      <info><name>Agri Hub</name></info>
      <ads>
        <ad guid="ad-5001" category_id="210">
          <info>
            <brand>John Deere</brand>
            <model>S780</model>
            <year>2023</year>
          </info>
          <price currency="EUR" taxtype="exclusive">320000</price>
          <contact_ids>
            <contact_id>12</contact_id>
          </contact_ids>
        </ad>
      </ads>
      <contacts>
        <contact id="12">
          <first_name>Max</first_name>
          <last_name>Mustermann</last_name>
          <email>max@agrihub.example</email>
        </contact>
      </contacts>
    </dealer>
  </dealers>
</exchange>
