Getting Started

Your First XML Exchange

This guide will introduce you to working with the XML format. The XML definition is a shared exchange format for both integration directions: It is used to send data to technikboerse or to receive data from technikboerse.

Perspective and Terminology ("Import" / "Export")

The terms "Import" and "Export" depend on your perspective.

  • Partner → technikboerse: Sending data to technikboerse (an "Export" from the partner's perspective, an "Import" from our perspective).
  • technikboerse → Partner: Receiving data from technikboerse (an "Import" from the partner's perspective, an "Export" from our perspective).

To avoid misunderstandings, this documentation generally uses explicit directional labels. The structure of the XML exchange file remains identical; only the transport and scheduling differ.

Tutorial

Technical Quick-Start (XML)

This guide walks you through creating and processing a valid XML exchange file.

A. Send data to technikboerse (Partner → technikboerse)

The partner creates the XML file with ads and provides (or uploads) it. technikboerse processes the file regularly according to the agreed schedule.

B. Receive data from technikboerse (technikboerse → Partner)

technikboerse generates the XML file containing the inventory data. The partner downloads (or receives) the file and processes it in their system.

1

The XML Root (exchange)

Every exchange file starts with the <exchange> element. This contains global metadata about the exchange.

<exchange>
  <senderName>your-provider-id</senderName>
  <exportDate>2024-05-12T06:00:00</exportDate>
  <transferMode>full</transferMode>
  <dealers> ... </dealers>
</exchange>

See the Root Element Reference for details on transferMode

2

The Dealer Block

Inside <dealers>, add your dealer. The guid is the primary key.

<dealer guid="dealer-unique-key-123">
  <info>
    <name>Sample Machinery Ltd.</name>
  </info>
  <ads> ... </ads>
  <contacts> ... </contacts>
</dealer>

Learn more about Dealer Attributes

3

Define a Contact Person

Contacts are defined at the dealer level and referenced by machines. Define them in the <contacts> container. 

<contact id="1">
  <first_name>John</first_name>
  <last_name>Doe</last_name>
  <email>j.doe@example.com</email>
</contact>

Check the Contact Reference for fields like gender and phone

4

The Machine (ad)

The <ad> element represents the machine. Place it inside the dealer's <ads> container. 

<ad guid="machine-789" category_id="210">
  <info>
    <brand>Fendt</brand>
    <model>724 Vario</model>
    <year>2022</year>
  </info>
  <price currency="EUR" taxtype="inclusive">185000</price>
  <contact_ids>
    <contact_id>1</contact_id>
  </contact_ids>
</ad>

Detailed field lists can be found in the Ad Reference and Prices & Media
