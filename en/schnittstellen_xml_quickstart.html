XML Integration

Technical Quickstart

This guide introduces you to the creation and processing of a valid XML exchange file for the technikboerse system.

Checklist

XML Prerequisites

Infrastructure

  • Transport method (FTP/HTTP) clarified
  • Server credentials provided
  • File naming convention agreed upon

Data Logic

  • Deletion logic strategy chosen
  • Image provision (URL/path) clarified
  • Unique dealer GUIDs available
  • Unique machine IDs available
Tutorial

Exchange File Structure

1

The XML Root (exchange)

Every exchange file begins with the <exchange> element. It contains global metadata.

<exchange>
  <senderName>your-provider-id</senderName>
  <exportDate>2024-05-12T06:00:00</exportDate>
  <transferMode>full</transferMode>
  <dealers> ... </dealers>
</exchange>
2

The Dealer Block

Within <dealers>, you add your dealer. The guid is the primary key.

<dealer guid="dealer-unique-key-123">
  <info><name>Muster Landtechnik GmbH</name></info>
  <ads> ... </ads>
  <contacts> ... </contacts>
</dealer>
3

The Machine (ad)

The <ad> element represents the machine. It is placed in the dealer's <ads> container.

<ad guid="machine-789" category_id="210">
  <info>
    <brand>Fendt</brand>
    <model>724 Vario</model>
  </info>
  <price currency="EUR" taxtype="inclusive">185000</price>
</ad>

Full Minimal Example

<?xml version="1.0" encoding="UTF-8"?>
<exchange>
  <senderName>provider-demo</senderName>
  <exportDate>2024-05-12T06:00:00</exportDate>
  <transferMode>full</transferMode>
  <dealers>
    <dealer guid="dealer-1001">
      <info><name>Agri Hub</name></info>
      <ads>
        <ad guid="ad-5001" category_id="210">
          <info>
            <brand>John Deere</brand>
            <model>S780</model>
          </info>
          <price currency="EUR" taxtype="exclusive">320000</price>
        </ad>
      </ads>
    </dealer>
  </dealers>
</exchange>
