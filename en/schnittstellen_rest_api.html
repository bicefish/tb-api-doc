Integration Overview

REST API

This page provides a functional and architectural overview of the technikboerse REST API. It serves as a central entry point for integration and provides guidance on how it relates to the XML interface. The authoritative technical documentation for endpoints is maintained separately in the REST API Reference.

Quick Specs

Technical Summary

Technical Reference api.technikboerse.com/doc/html
Base URL https://api.technikboerse.com
Authentication Bearer Token (Authorization header)
Format & Model JSON / JSend response model
URI Pattern /{lang}/{version}/{endpoint}
Permissions Scope-based access
Context

Classification

Role of the REST API

While the XML interface is optimized for bulk data and batch processing, the REST API offers granular, request-based access. It is the primary tool for real-time interactions.

Documentation Split

This overview focuses on integration concepts. All technical endpoint details (parameters, examples, schemas) are exclusively documented in the REST API Reference.

Authoritativeness

The external REST API Reference is the authoritative source for technical specifications. This page serves as a conceptual guide within the overall system.

Relation to Import/Export

The REST API supports both read and write operations in real-time. In contrast to asynchronous XML workflows, the REST API provides immediate success or error feedback per request. Applications should log and evaluate these response messages to identify integration errors promptly.

Integrations

Typical Use Cases

Selective Queries

Targeted retrieval of individual ads, dealer data, or reference information (categories, attributes) without having to process a full XML Exchange.

Interactive Integration

Connecting web frontends or mobile apps that directly access technikboerse resources or query status information in real-time.

Point Updates

Targeted update or maintenance of specific resources via dedicated endpoints, provided they are enabled for API access.

Validation & Mapping

Synchronizing local data sets with current technikboerse reference data during the data entry process in the source system.

Comparison

Distinction: XML vs. REST

Aspect REST API XML Interface
Main Focus Targeted operations & real-time lookups Bulk transfer & batch processing
Data Strategy Selective retrieval / Point updates Full / Delta Export (Inventory sync)
Integration Type Request/Response (Sync/Async) File-based exchange (FTP/Download)
Responsibility Individual resources & references Entire data set (Authority)

Important

The REST API should not appear in the documentation as an alternative way of writing the same XML interface. Both access paths have different integration models, expectations, and error patterns.
